# 全方位健康急救與車禍指南

一個整合車禍處理、症狀查詢、疾病衛教、藥品對照與 AI 輔助分析的健康資訊網站，目標是讓使用者在突發狀況或日常不適時，能快速找到一般性的處置指引。

線上網站：<https://healthemergency.vercel.app>

> ⚠️ **免責聲明**
> 本網站所有內容僅供一般健康衛教參考，不能取代醫師診斷或治療。遇到緊急狀況（呼吸困難、意識不清、嚴重出血、胸痛、中風徵象等），請立即撥打 **119**。AI 分析結果同樣只是參考資訊，不是醫療診斷。

## 專案結構

```
health_emergency/
├── index.html            # 前端主頁面（HTML / CSS / JavaScript，所有資料內嵌於此）
├── api/
│   └── vision/
│       └── analyze.js    # Vercel Serverless Function：呼叫 Gemini 進行分析
├── vercel.json           # 設定 analyze.js 的最長執行時間
├── sw.js                 # Service Worker（離線功能）
├── manifest.webmanifest  # PWA 設定（可加入手機主畫面）
├── icon.svg / icon-192.png / icon-512.png / apple-touch-icon.png   # 應用程式圖示
└── README.md
```

- 前端為單一 `index.html`，使用 Tailwind CDN 與 Font Awesome，不需要建置步驟。
- 疾病資料位於 `index.html` 內的 `window.KB_DISEASES`（疾病大百科）與 `window.KB_LIFE`（全齡全身疾病）。要新增項目，依既有格式加一行陣列即可。
- AI 後端端點寫在 `index.html` 的常數 `AI_VISION_ENDPOINT`，目前為 `https://healthemergency.vercel.app/api/vision/analyze`。

## 部署（Vercel）

1. 將此 GitHub repository 匯入 Vercel，使用預設設定部署。`api/vision/analyze.js` 會自動成為 `/api/vision/analyze`。
2. 在 Vercel 專案 **Settings → Environment Variables** 設定：

   | 變數 | 必填 | 說明 |
   | --- | --- | --- |
   | `GEMINI_API_KEY` | ✅ | 從 Google AI Studio 取得的 API 金鑰，**只放在伺服器端** |
   | `ALLOWED_ORIGIN` | 選填 | 允許呼叫 API 的網站來源，例如 `https://healthemergency.vercel.app`。只填 origin，結尾不加 `/`。若前端與 API 在同一個 Vercel 專案，可不設定 |
   | `GEMINI_MODEL` | 選填 | 預設為 `gemini-3.5-flash-lite`。若該模型不可用，改成 AI Studio 中可用且支援圖片輸入的模型名稱 |

3. 儲存環境變數後 **重新部署** 才會生效。
4. 部署完成後，用瀏覽器直接開 `/api/vision/analyze`，看到「只接受 POST 請求。」代表後端已上線。

> 🔑 API 金鑰絕對不要寫進 `index.html`、提交到 Git，或放在任何公開檔案中。

### 若前端放在 GitHub Pages 等其他網域

GitHub Pages 是純靜態網站，無法執行後端程式，AI 功能仍必須呼叫 Vercel 上的 API。此時需要：

- 把 `index.html` 中的 `AI_VISION_ENDPOINT` 設為完整的 Vercel 網址（使用正式網域，不要使用帶亂碼的部署專用網址，後者可能被 Vercel 存取保護擋下）。
- 在 Vercel 設定 `ALLOWED_ORIGIN` 為該網站的 origin（例如 `https://你的帳號.github.io`）。

## AI 分析說明

**分析類型**：身體症狀／皮膚／傷口、藥膏／藥品包裝、症狀加藥膏。可另外選擇患者年齡層，讓建議依新生兒、嬰幼兒、孕婦、高齡者等調整。

**回覆內容**：
- 症狀：觀察重點、常見可能原因、居家照護、**讓症狀改善的方法**（非藥物方式、常見的非處方藥膏／藥品類型與適用情境、需醫師評估的藥物、特殊族群限制、多久沒改善應就醫）、就醫警訊、建議科別。
- 藥膏／藥品：僅依包裝上可見文字辨識品名與成分，說明一般用途、使用前須知與注意事項、停用時機。

**安全設計**：
- AI 不做確定診斷、不開處方，不提供任何藥物劑量、次數或療程；使用方式以包裝、仿單與醫師藥師指示為準。
- 一律列出需儘快就醫的警訊，可能危及生命時建議立即撥打 119。
- 顯示結果前會先跳脫所有 HTML，再轉成排版，避免注入程式碼。

### 使用額度（Gemini 免費層）

- 免費層的可用模型與每分鐘／每日請求數（RPM、RPD）、token 數（TPM）會隨模型、專案與帳戶狀態變動，Google 不保證固定配額。請到 Google AI Studio 的 **Rate limits** 頁面查看此專案的實際額度。
- 超過額度會回傳 429，網頁會提示稍後再試。
- 免費層送出的內容可能被 Google 用於改善其產品；付費層的資料處理規則不同。使用前請參閱 Google 最新的 Gemini API 條款與資料使用政策。
- 升級付費只需在同一個 Google 專案綁定帳單，通常不用更換金鑰或修改程式。

## 隱私與檔案處理

- 使用者必須先勾選同意傳送至 Google Gemini，才會呼叫 API；未同意時瀏覽器不會送出任何請求。
- 照片僅接受 JPG、PNG、WebP。原始檔超過 15 MB 會在瀏覽器端拒絕；瀏覽器會將照片縮至最長邊 1280 px 並轉為 JPEG（降低手機記憶體用量，避免切換 App 後頁面被系統重新載入），以符合 Vercel 請求大小限制；後端另限制圖片內容約 3 MB。
- 後端不將照片或分析內容寫入磁碟、資料庫或日誌，API 回應設為 `no-store`。
- 照片只暫存在使用者當前頁面的記憶體中，離開頁面或更換照片即清除。
- 請勿上傳可識別個人身分的照片，或不願交由 Google 處理的內容。
- 公開網站的 API 端點可能被第三方濫用。CORS 只限制瀏覽器來源，並不是身分驗證。正式公開前，建議在部署平台加上速率限制或濫用防護，並定期檢查 Vercel 與 Google AI Studio 的使用量。

## 手動驗收清單

1. **未同意**：選一張照片但不勾同意，按分析。應顯示尚未同意，且 Network 中不出現 `/api/vision/analyze` 請求。
2. **照片分析成功**：勾同意並送出有效照片，應看到處理中狀態、排版正常的結果與非診斷提醒。
3. **純文字分析**：不上傳照片，只填症狀描述並勾同意，應能取得分析結果。
4. **藥膏分析**：選「藥膏／藥品包裝」並上傳包裝照片，結果應只引用包裝上可見的資訊，且不含劑量。
5. **格式與大小錯誤**：選超過 15 MB 的檔案、PDF 或其他非圖片，應提示重選且不送出。
6. **沒有金鑰**：暫時移除 `GEMINI_API_KEY` 並重新部署後送出，應提示管理者需設定金鑰，且不洩漏伺服器細節。測完請恢復設定並重新部署。
7. **API 錯誤**：以無效金鑰或不可用模型測試，頁面應提示檢查設定或稍後再試。
8. **離線**：開啟網站一次後，把手機切到飛航模式再重新開啟，頁面與疾病資料仍可使用，且出現離線提示；按 AI 分析會提示需要網路。
9. **拍照後切換 App**：用手機拍照並分析，再切到別的 App 後回來，頁面不應重新載入。
10. **頁面導覽**：每個大分頁左上角的「← 首頁」都能回到首頁；首頁搜尋「紅疹」「盲腸」等關鍵字能跳轉到對應項目。
11. **緊急提示**：確認 AI 頁面清楚說明資料會傳至 Google Gemini、網站不保存照片，並提示緊急狀況撥打 119。

## 離線使用

網站已加入 Service Worker 與 PWA 設定：

- **第一次**在有網路的情況下開啟網站，瀏覽器會自動把頁面、疾病資料、樣式與圖示存起來，並顯示「已完成離線準備」。之後沒有網路也能查看急救指南、疾病大百科、全齡疾病、穴位、藥品對照、BMI 等內容。
- 離線時畫面上方會出現提示，**AI 分析需要網路**，離線時會直接說明，不會送出請求。
- 頁面採「網路優先」：有網路時永遠載入最新版，連不上才使用已儲存的版本。
- AI 分析的 API（`/api/`）不會被快取。
- 可在手機瀏覽器選「加入主畫面」，像 App 一樣開啟（iPhone：Safari 分享 → 加入主畫面；Android：Chrome 選單 → 安裝應用程式）。
- 更新網站後若想強制所有使用者重新抓取資源，把 `sw.js` 內的 `CACHE_VERSION` 加 1。
- Service Worker 只在 `https://` 或 `localhost` 下運作，直接以本機檔案（`file://`）開啟時不會有離線功能。
- 樣式與圖示的 CDN 檔案（Tailwind、Font Awesome）會在第一次連線時一併存起來；清除瀏覽器資料後需要再連線一次。
